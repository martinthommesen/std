# STD glossary

- **Form rule:** a conditional required, read-only, hidden or choice restriction attached to a field of a class and inherited by its subclasses, with optional hidden-boolean correction and form guidance. Form rules constrain browser forms; record rules and access rules govern record writes (Contracts 5.10).
- **Proposed record:** the record an operation would produce, formed from stored values, supplied values and applicable derive rules. On create there is no stored image (Contracts 4.10).
- **Form-state verdict:** the caller-masked field states and derived proposed values returned for one versioned form proposal. It binds that browser proposal and grants no authority to write a record (Contracts 5.8, 6.3).
