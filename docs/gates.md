# Gate map

This file maps every bullet of the plan's Stage 0 gate, Step 1 gate and Step 2 gate, and the guarantees of Step 2's workstreams (`docs/plan.md`), to the tests that prove it and the CI step that runs them. Compound bullets are split into their sub-claims.

Last updated 2026-10-22 on branch `ws/2b-web-pages` at 0e0150d, with `main` at 4c2d165 merged in (b6b7c72). The Step 2 rows were written by reading each test's body at that commit. The Stage 0 and Step 1 rows are as `ws/1-gate-final` left them: rows 0.6 and 1.4 to 1.8 were rechecked against the tests it adds, after its review and the full gate audit at 0fae3ff.

How statuses are judged:

- **covered**: a test asserts the claim as the plan states it. Code that implements the claim without a test asserting it does not count.
- **partly covered**: tests assert part of the claim. The Gaps column says exactly what is missing.
- **not covered**: no test asserts the claim.

A status says that the assertions exist. It does not say that a CI run passed. This map was written without running the tests.

`ws/1a-schema-lifecycle` (8e518d6) and `ws/1-gate-gaps` (a66957d) are merged into `main` and into this branch. The tests marked **(1A)** below came with 1A.

CI steps are the `- name:` entries in `.github/workflows/ci.yml`. CI runs them against a `postgres:18` service:

- **Test**: `pnpm test`. Vitest runs every workspace package under `packages/*`, `apps/*` and `examples/*`, and `bench`.
- **Toolchain canaries**: `pnpm test:canaries` (`tooling/test/`).
- **Quickstart**: `pnpm quickstart:ci`, the Step 1 runnable result (see "Runnable results").
- **Browser tests**: `pnpm --filter @std/web test:browser`, the step "Browser tests (the web app in Chromium against std serve)". It runs the files in `apps/web/test/browser/` in Playwright's Chromium against a real `std serve` on a disposable test database; the DevTools tests also use the Vite dev server. **Test** runs the web app's story, scene and unit tests (`apps/web/src/**/*.test.ts`), not these.
- **Type check**, **Tooling checks** and **Lint and format** are named where they matter.
