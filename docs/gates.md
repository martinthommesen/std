# Gate map

This file maps every bullet of the plan's Stage 0 gate and Step 1 gate (`docs/plan.md`) to the tests that prove it and the CI step that runs them. Compound bullets are split into their sub-claims.

Last updated 2026-10-22 on branch `ws/1-quickstart`, after merging `main` at 8e518d6.

How statuses are judged:

- **covered**: a test asserts the claim as the plan states it. Code that implements the claim without a test asserting it does not count.
- **partly covered**: tests assert part of the claim. The Gaps column says exactly what is missing.
- **not covered**: no test asserts the claim.

A status says that the assertions exist. It does not say that a CI run passed. This map was written without running the tests.

`ws/1a-schema-lifecycle` (8e518d6) and `ws/1-gate-gaps` (a66957d) are merged into `main` and into this branch. The tests marked **(1A)** below came with 1A.

CI steps are the `- name:` entries in `.github/workflows/ci.yml`. CI runs them against a `postgres:18` service:

- **Test**: `pnpm test`. Vitest runs every workspace package under `packages/*`, `apps/*` and `examples/*`, and `bench`.
- **Toolchain canaries**: `pnpm test:canaries` (`tooling/test/`).
- **Quickstart**: `pnpm quickstart:ci`, the Step 1 runnable result (see "Runnable results").
- **Type check**, **Tooling checks** and **Lint and format** are named where they matter.
